# Storage Unit Converter - Featured Version

## Purpose
The Storage Unit Converter is a simple Python program that converts
storage capacity from gigabytes (GB) to megabytes (MB) and
kilobytes (KB).

The program asks the user to enter a storage value in GB,
calculates the equivalent value in MB and KB, and displays
the results.

## How to Run the Program
1. Install Python 3 on your computer.
2. Open a terminal or command prompt.
3. Navigate to the folder containing `storage_emulator.py`.
4. Run the following command:

   python storage_emulator.py

## Example Input/Output

Input:
Enter storage in GB: 2

Output:
Storage in MB: 2048.0
Storage in KB: 2097152.0

## Conversion Formulas
- MB = GB × 1024
- KB = MB × 1024
